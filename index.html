怎样让一个人在三十秒内，理解一件花了几十亿年才发生的事？答案往往不是更多的文字，而是一个可以被拖动、缩放、倒带的世界。

我的工作流横跨三维建模、实时渲染与数据工程：在 Blender 里用节点程序化地生成地形、生物群系与云层，烘焙成贴图；在浏览器里用 Three.js 与 GLSL 还原大气散射、海面高光与昼夜交替；再把地质、解剖与人口数据编成可以播放的时间轴。

  • 实时三维与着色器
  • Blender 程序化建模
  • 数据可视化叙事
  • 离线优先的 Web 应用
  • 科普与教育产品
04

制作管线

数据 → 烘焙 → 实时 → 叙事
  1. S1 · 数据

    采集与整理

    把海岸线、地形、解剖网格与考古遗址整理成可烘焙、可索引的结构：Natural Earth 栅格化为 8K 陆地遮罩，解剖模型拆成 2331 个独立命名的部件。

    Natural Earth · Z-Anatomy · BodyParts3D · Node
  2. S2 · Blender

    程序化与烘焙

    用 Cycles 节点合成高度、反照率、法线、云层与夜灯，烘焙成 4K/8K 贴图；场景与模型整理后导出 glTF，不依赖在线模型库。

    Cycles · Geometry Nodes · Python bpy
  3. S3 · 实时

    浏览器渲染

    自写 GLSL 还原大气散射、晨昏线、海面高光与随视角变化的透视材质；渲染循环离屏即暂停，只在画面变化时重绘。

    Three.js · GLSL ES 3.0 · WebGL
  4. S4 · 叙事

    时间轴与交互

    把数据编成可以拖动的时间轴：地质年代与迁徙路线，或者人体的一天。所有文案与数据随包附带，离线可用。

    Vite · 离线打包 · 零外部 API
