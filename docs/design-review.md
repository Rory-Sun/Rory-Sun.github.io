# 设计复审清单

每两天一次，对照世界一流个人主页的标准审视首页。只做能被论证说服的改动，拒绝无理由的视觉改动。

## 流程

```bash
npm run build && npm run screenshots
```

逐张看完 `screenshots/` 下的六张整页图（桌面 / 平板 / 手机 × 深色 / 浅色），需要时裁剪放大细看局部。改完再跑一次，对比前后。最后 `npm run check` 并提交，提交信息里写清每条改动的理由。

## 检查项

### 中文排版

中文每个字都是合法断点，浏览器不认识词边界，所以断行问题在中文站点比英文站点严重得多。

- **禁止 `text-wrap: balance`** 用于中文标题。它为了让各行等长会在词中间断开（曾把"转动的世界"断成"转动的世 / 界"）。用显式 `<br>` 控制断点，配合 `text-wrap: pretty`。
- 标题所在容器必须**宽于**最长一行的实际宽度。估算方式：汉字宽度约等于字号，`12 字 × 46px = 552px`。
- 多段短语拼成的说明文字（用 `·` 分隔的那种），每段用 `white-space: nowrap` 包住，只允许在段与段之间断开。
- 数字加单位、以及不该拆开的固定词组，用 `<span class="nb">` 包住（`.nb { white-space: nowrap }`）。已经踩过的坑：「三十秒」断成「三 / 十秒」、「46 亿年」断在数字和单位之间。
- **字间距**：中文不要超过 `0.16em`。`0.3em` 以上只适合纯拉丁字母的小型大写标签。
- 检查每个断点：有没有孤字成行，有没有把一个词拆开，有没有标点出现在行首。

### 首屏

- 手机端（390×844）标题必须在折叠线以上。视觉元素再好看，也不能把主张挤下去。
- 标题是一个主张，不是自我介绍。信息量最低的那一行（"你好，我是某某"）应该删掉，名字放在导航栏或 eyebrow 里。
- 首屏底部要有继续浏览的暗示。

### 视觉一致性

- 不要出现看起来像占位符的东西。裸露的大号 emoji 是最常见的一种，应该放进有设计感的容器里。
- 深浅两套主题下都要检查一遍，尤其是阴影、光晕、玻璃拟态这类依赖背景色的效果。
- 小字对比度不低于 4.5:1。

### 性能与动效

- 首屏图片用 WebP 并配 `srcset`，不要跨站引用大图。
- 所有动效在 `prefers-reduced-motion: reduce` 下必须退化。
- Lighthouse 的性能分在 CI 里因为没有 GPU 而偏低，这部分可以忽略；可访问性、最佳实践、SEO 三项必须保持全绿。

### 截图脚本的坑

`npm run screenshots` 必须在 `npm run build` **之后**跑，否则拍的是上一次的构建产物。判断方法：比较 `dist/` 和 `screenshots/` 的时间戳，或者看整页高度对不对。

海报是懒加载的，只等 `img.complete` 会拍到黑框，必须等 `img.decode()`。

## 已知的待办候选

按优先级排列，每次复审时重新评估。2026-10-11 首页改版为「观测台」控制台布局，下列条目已按新结构重写。

**已在改版中解决**：「关于我」缺少事实（现为操作员档案：苏州、从业 10 年、接受合作）；「技术」只讲地球纪元（现为四段管线加覆盖矩阵）；月球 / 生命之树与地球纪元的从属关系（现为索引里的子模式行）；图标按钮低于 44px（现为 38px 顶栏按钮与 44px 主按钮）；琥珀色闲置（现为仪器色）。

**内容**

1. **内容层（路线图第 2 项）**：更新日志区、每个作品的技术拆解、中英双语。
2. **管线矩阵里溪畔秋日的「数据」「叙事」两格**是根据仓库内容推断的，需要本人确认。
3. **九个特性条目已不再显示 emoji**，但档案里的特性仍是文字列表，可以考虑配一张每件作品的技术截图。

**视觉与交互**

4. **给首屏地球一条时间轴**，让它成为论点本身。需要从 earth-chronicle 管线烘焙各地质年代的贴图，跨仓库。
5. **演示失败没有兜底**：浏览器在 iframe 被拦截时同样会触发 load 事件。改版加了「关闭演示」按钮，至少能退出死掉的画面，但仍识别不了失败。
6. **横屏手机与 320px 宽度**：截图脚本没有这两种视口。
7. **字体体积**：三套拉丁字体共 8 个字重，woff2 合计约 170KB。可以裁掉 IBM Plex Sans 500 与 JetBrains Mono 500。

**已知但不改**

- 给地球加键盘旋转：在装饰性元素上加 `tabindex` 和 `role="application"` 会把读屏软件切出浏览模式，弊大于利。
- 不用 Google Fonts：在中国大陆基本不可达，字体一律用 @fontsource 自托管。

## 截图脚本的坑（补充）

WebGL 画布必须开 `preserveDrawingBuffer`，否则渲染循环在离屏时暂停后，截图会抓到空缓冲区——地球曾因此在全部六张图里隐形，而每一轮复审都在看这批图。
